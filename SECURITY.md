# Security policy

Zebra keeps your Zepp sign-in and health data on your own Mac. If you find a way that data could leak (credentials, tokens, raw health data, precise GPS, or the local API answering beyond `127.0.0.1`), please report it privately first.

## How to report

- Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability").
- Include the Zebra version, your macOS version and the steps to reproduce. Leave out your own tokens, account details and health values; say where they appear instead.
- Please do not open a public issue for an unfixed vulnerability.

## Supported versions

Only the latest release receives fixes.

Zebra is a fork of [ZeppBridge](https://github.com/lingcang728/ZeppBridge). If the issue is also in ZeppBridge, report it to them as well.
